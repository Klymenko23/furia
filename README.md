# Furia

Система для перевізника: автопарк (тягачі й причепи), водії, документи з термінами, витрати.
Next.js 15 + Supabase. Кожна фірма отримує свою окрему копію: свою базу Supabase і свій сайт.

## Що вже є

- **Автопарк.** Тягачі й причепи окремими картками. У тягача — «звичайний причіп», стан (вільна, у рейсі, на ремонті), пробіг, фірма, VIN, обʼєкт Wialon.
- **Водії.** Схема оплати: відсоток від фрахту (15/20% або свій), відсоток + добові, ставка, сума за рейс. Закріплений тягач.
- **Документи з термінами.** ОСЦПВ, зелена карта, КАСКО, техогляд, тахограф, ЄКМТ, CMR-страхування, документи водія тощо. Кольорові позначки: прострочено, ≤7 днів, ≤30 днів.
- **Витрати.** Категорії (пальне, дороги, штрафи, колеса, запчастини, ТО, документи, витрати водія, добові…), магазини й постачальники (додаються самі), хто платив, пробіг при заміні. Звіт за місяць по категоріях і машинах.
- **Wialon.** Вхід через сторінку Wialon (токен лише на перегляд), привʼязка тягача до обʼєкта, позиція, швидкість і час останнього сигналу на картці машини.
- **Рейси.** Маршрут з кількома точками, вантаж, митниці, кордон, RMPD для Польщі, тягач/причіп/водій, фрахт, фірма, форма оплати, ПДВ, відстрочка. 10 етапів від заявки до оплати, документи (ТТН/CMR, рахунок, податкова, оригінали з ТТН пошти), строк оплати й прострочка. Прибуток рейсу: фрахт − відсоток за проведення − водію − витрати рейсу.
- **Зарплата.** За місяць по кожному водію: відсоток, добові по країнах, ставка або сума за рейс + витрати зі своїх − аванси.
- **Замовники.** База з каналом заявок, напрямками, відстрочкою, боргами й простроченнями.
- **Налаштування.** Фірми власника (ФОП/ТОВ/ПП, оподаткування, відсоток за проведення), добові по країнах, постачальники, користувачі й ролі.

Ролі: **власник** (усе), **диспетчер** (усе, крім фірм і доступів), **бухгалтер** (бачить усе, вносить витрати). Права перевіряє сама база (RLS), а не лише кнопки.

## Як запустити нову фірму

1. **Supabase.** Створіть проєкт → SQL Editor → вставте `supabase/migrations/0001_init.sql` → Run.
   Потім `supabase/migrations/0002_wialon.sql` (Wialon) і `0003_trips.sql` (рейси й замовники).
   За бажанням `supabase/seed.sql` (стартові машини й водій).
2. **Перший користувач.** Supabase → Authentication → Users → Add user (пошта + пароль, Auto Confirm).
   Перший користувач у базі автоматично стає **власником**. Решту додаєте вже в системі: Налаштування → Доступ.
3. **Ключі.** Скопіюйте `.env.example` у `.env.local` і вставте ключі з Supabase → Project Settings → API.
   `SUPABASE_SERVICE_ROLE_KEY` — секретний: тільки на сервері, ніколи в чат чи в код.
4. **Локально:** `npm install`, потім `npm run dev` → http://localhost:3000
5. **На сервер:** Vercel → Import з GitHub → додати ті самі три змінні → Deploy.
